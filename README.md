# Lucky Lounge

A responsive casino-style local demo app inspired by the supplied reference screenshot.

## Run locally

Open `index.html` in a modern browser. No build step or internet connection is needed.

## Features

- Game catalog with search, filters, sorting, and favorites
- Local nickname profile, demo wallet, daily demo coin bonus, and play history
- Playable slot-style demo using virtual coins only
- Responsive desktop and mobile layouts

This is a front-end demo. It has no backend, real accounts, deposits, withdrawals, or cash prizes. Demo coins have no cash value.
